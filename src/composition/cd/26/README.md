《太阳之子》

发行日期：2026年3月25日

专辑简介

《太阳之子》(Children of the Sun)是周杰伦的第16张个人专辑，于2026年3月25日全球数字发行。专辑名称源于张学友在2023年香港演唱会期间赠送的昵称——当时连日大雨但每场演出前都会放晴，张学友幽默认证周杰伦为"太阳之子"。

制作背景

整张专辑共收录13首作品，包含12首全新创作歌曲及特别收录单曲《圣诞星》。同名主打《太阳之子》MV长达6分58秒，耗资超2000万元，由好莱坞特效团队Weta Workshop操刀，串联30幅世界名画。

专辑上线10小时在QQ音乐平台售出超131万张，达成殿堂史诗唱片认证。

创作亮点

- **风格多元**：横跨哥特摇滚、西部民谣、中国风、复古爵士等多种风格
- **制作精良**：维也纳交响乐团弦乐录制，数十轨堆叠技术提升专辑质感
- **情感真挚**：《那天下雨了》《乡间的路》等歌曲展现成熟的人生感悟
- **特别收录**：2023年单曲《圣诞星》重新收录，作为给歌迷的礼物

专业评价

知名乐评人耳帝评价："整体来说，这一张肯定是比上一张《最伟大的作品》要好的，整体是好听的"。其中《女儿殿下》被评为"整张专辑最佳编曲"。

争议与批评

主打歌《太阳之子》评价两极，部分乐评认为旋律无记忆点、编曲元素堆砌。有观点认为部分歌曲像是旧作的"3.0、4.0版本"，缺乏突破性的音乐性。
